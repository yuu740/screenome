# screenome

A short movie promotion-web, built using HTML, CSS, JavaScript. 
This short movie is a drama with an educational theme about gadget addiction and the importance of reconnecting with real life.

###  🎬 Synopsis Short Movie 
In a new digital era, technology has become an inseparable part of human life. For Raka, a college student, the phone screen is no longer just a communication tool—it has gradually turned into his own world. Unknowingly, this habit begins to affect his relationships, education, and life as a whole. However... an unexpected event shakes his world, forcing him to reconsider the choices he has made. Amidst the ever-dominating digital flow, will Raka be able to rediscover the true meaning of the real world?

### ⚙️ Features

- **Interactive-hero section** : If you click the title of screenome, it can glitch. 
- **Media Play** : Trailer playback (manual play) and a button to watch the full movie (via embedded YouTube iframe).
- **Behind the Scene Video**
- **Looped Slide for Blooper Video with captions**
- **Simple, responsive layout for promotional landing page.**
